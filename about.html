About This Website

Welcome to our Hotel Table Booking Website — a simple and user-friendly platform built as part of a 3rd-year Web Development academic project.

This website allows users to easily:

  • Book tables in advance at restaurants or hotels
  • View and explore the food menu
  • Purchase extra services or products through the shop

The project demonstrates how web development technologies can be used to solve real-life problems by creating an online reservation system that reduces wait times and improves customer experience.

Technologies Used:

  • Frontend: HTML, CSS
  • Backend: Python (Flask)
  • Database: SQLite
