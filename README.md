# Restaurant Table Booking Web Application

This is a restaurant table booking web application that allows customers to view the menu, book tables, and make reservations online. It also includes an admin panel for managing reservations and viewing customer details.

# Features

Homepage: Welcome page with options for customers and restaurant admin.

# Customer Functionality:

View menu (with Indian, Vietnamese, and Korean dishes)

Browse dishes with prices

Book tables with date, time, and number of guests

Submit booking requests

# Admin Panel :

View reservations

Manage customer details

Monitor table availability

Responsive Design: Works well on desktop, tablet, and mobile.

# Technologies Used

HTML, CSS, JavaScript – Frontend

Python Flask – Backend server and routing

SQLite – Database for storing bookings and user details

Bootstrap – Responsive layout

Jinja2 – Templating engine for dynamic HTML
